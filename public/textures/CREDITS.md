# Texture credits

The Earth textures in this directory are NASA imagery, which is in the public
domain. They were obtained from the `three-globe` package (MIT licensed), which
redistributes them, and re-encoded here for the web (resized, and converted to
progressive JPEG / WebP).

| File | Source | Notes |
| --- | --- | --- |
| `earth-day.jpg` | NASA Visible Earth — Blue Marble | 4096x2048. Surface colour. |
| `earth-night.jpg` | NASA Earth Observatory — Earth at Night | 2048x1024. City lights, shown only on the unlit side of the terminator. |
| `earth-topology.jpg` | NASA — elevation/topography | 2048x1024, greyscale. Drives a subtle surface bump. |
| `earth-clouds.webp` | NASA — cloud cover composite | 1536x768 with alpha. |

NASA does not endorse this project. See
<https://www.nasa.gov/nasa-brand-center/images-and-media/> for NASA's media
usage guidelines.

The Moon texture is **not** photographic: it is generated procedurally in
`lib/moonTexture.ts`. It is a plausible cratered surface, not a lunar map, and
the site says so rather than implying otherwise.
